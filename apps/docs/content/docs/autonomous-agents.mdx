**In development.** WooStack's autonomous agent setup is being developed around a coordinated team
of agents with defined responsibilities. This page describes the direction; installation and
configuration instructions are not available yet.

## A team with defined responsibilities

The intended setup separates coordination, implementation, and specialist review. Coordination
turns a request into a clear scope, assigns ownership, and keeps related work consistent.
Implementation produces the requested change and checks its behavior. Specialist review examines
the concerns relevant to that change, such as design, functional correctness, security, or reliability.

Separate responsibilities give each agent a focused job and make gaps easier to see. They also
make handoffs necessary: a reviewer needs the actual artifact and enough context to assess it.
A completion report alone cannot establish that a change works or has passed independent review.

## Bounded handoffs and review

A handoff should carry an objective, relevant context, allowed actions, expected output, and the
evidence needed to verify the result. Clear boundaries help the next agent continue the work
without treating background information as permission to expand it.

An agent's report should distinguish what it changed, what it checked, and what remains uncertain.
Review should inspect the delivered artifact or exact revision and report its findings and coverage.
That keeps implementation finished, review assigned, and review passed as separate states.
These are principles for the intended operating model; they do not describe an available routing
or approval engine.

## How it relates to agent skills

[Agent skills](/docs/agent-skills) provide task workflows inside a coding harness. The autonomous
setup concerns the team's ongoing organization and coordination: how responsibilities are divided,
work is handed over, and results are reviewed.

The existing [Orchestrate workflow](/docs/guides/coordinate-work) coordinates approved tasks using
skills and the coding harness's available capabilities. It is available separately from the
autonomous setup. Its guide does not install or configure this developing team setup.

## Current status

The setup's supported environments, installation, and configuration remain to be documented and
verified. There is no setup procedure to follow yet. The [tech stack](/docs/recommended-stack) and
[agent skills](/docs/agent-skills) can be used independently while this work is in development.

User decisions and permissions continue to bound the work. This overview grants no authority to
merge or deploy changes.
