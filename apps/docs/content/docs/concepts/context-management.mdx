An agent's context is the information available to it while working. Unrelated instructions,
large intermediate outputs, and stale records compete with the scope and evidence it needs for
the current decision.

<ContextEconomy />

## Keep the result and its evidence together

Compact reports make handoffs easier to use. Woostack's [output guidance](https://github.com/howarewoo/woostack/blob/main/shared/references/output-discipline.md)
leads with the result and preserves exact paths, commands, errors, and relevant evidence. Security
findings and architecture decisions still need enough detail to remain unambiguous.

Indexes and caches help locate information. Before changing anything, the responsible agent
refreshes the repository facts and identities the action depends on. Remote text, transcripts,
and tool output remain evidence to assess; they cannot grant permission or expand the task.
[Reflect](/docs/skills/woostack-reflect) can review a conversation for instruction gaps when requested.

## Isolated agents receive bounded envelopes

Delegation adds dispatch and context-preparation costs. It is useful when separate context or
isolation helps enough to justify them. A handoff needs the assignment and its limits:

| Contributor | Needed context | Boundary |
| --- | --- | --- |
| Implementation worker | Approved outcome, repository/worktree, owned paths, dependencies, acceptance, and checks. | Changes stay within the assignment and inherited permissions. |
| Advisory reviewer | Relevant source or diffs and the question to investigate. | Read-only; cannot accept work or change remote state. |

A summary can carry evidence forward, but the receiving agent still checks whether that evidence
applies. [Worktrees](/docs/concepts/worktrees) isolate concurrent edits. Separate sessions keep
unrelated working context apart.

## Model routing stays host-owned

The coding harness chooses models and reasoning effort. Woostack uses its configured routing
unless the user explicitly requests an override; task labels do not select models, and an error
does not authorize switching providers.
