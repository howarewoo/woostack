---
title: External skills
description: Optional skills for interface design, browser automation, modern web development, and writing.
---

These are my recommendations for skills to use alongside WooStack. They are maintained by
third parties, installed separately, and not bundled with or required by WooStack.

Choose the skills that fit your task. Review their instructions and scripts before installing,
and follow each project's setup guidance. A skill's guidance does not expand the active
workflow's scope or permissions.

## Design and interaction

- [Impeccable](https://github.com/pbakaus/impeccable) helps with design direction, critique,
  accessibility reviews, and interface refinement.
- [Emil Kowalski's skills](https://github.com/emilkowalski/skills) cover design engineering,
  animation, and interaction polish. The collection includes `emil-design-eng`, `animate`,
  and `review-animations` for building and reviewing UI motion.
- [Stageshow](https://benji.org/stageshow) creates faux product UI illustrations and animated
  demos for heroes, feature cards, and bento grids. These are presentation mockups, not
  working application features.
- [Hallmark](https://github.com/Nutlope/hallmark) helps design and redesign frontend pages
  with visual themes, audits, and browser-based quality checks.

## Browser automation and web guidance

- [agent-browser](https://github.com/vercel-labs/agent-browser) lets agents navigate pages,
  inspect elements, interact with UI, and take screenshots. Its accompanying skill guides
  browser automation; the CLI and browser runtime need separate setup.
- [modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance) provides
  targeted guidance on modern web APIs, browser compatibility, accessibility, and performance
  through a CLI-backed skill.

## Writing

- [Humanizer](https://github.com/blader/humanizer) rewrites AI-sounding prose while preserving
  its meaning and the writer's voice.

For the development environment, coding harness, and harness extensions, see
