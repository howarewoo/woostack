These are my recommendations for working with coding agents, not requirements for
using Woostack. They cover the development environment, agent harness, and design guidance. For application
technologies, see [Recommended tech stack](/docs/recommended-stack).

## Development environment and remote access

[Orca](https://orca.dev) is my recommendation for an IDE, or agent development environment
(ADE). It brings coding agents, worktrees, terminals, and code review into one application.

[Tailscale](https://tailscale.com/) provides remote access to your development machine over a
private network.

## Coding harness

[Pi](https://pi.dev/) is my recommended coding harness. Its core is deliberately small, with
extensions that add tools and change the terminal interface.

Enable Pi's built-in `grep`, `find`, and `ls` tools by default so agents can search and
explore the repository without writing shell commands for each lookup. Enable
[`codemode`](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/codemode.md)
to batch and chain tool calls in JavaScript, keeping intermediate results out of the
conversation. In `~/.pi/agent/settings.json`:

```json
{
  "defaultTools": ["+codemode", "+grep", "+find", "+ls"]
}
```

I use the following optional packages in my Pi setup. Woostack does not require them.
Extensions execute code, so review their source before installing them.

- [pi-zentui](https://github.com/lmilojevicc/pi-zentui) customizes the terminal UI, including
  the editor, messages, progress display, and footer.
- [@howarewoo/pi-subagents](https://github.com/howarewoo/pi-extended-subagents) delegates work
  to focused subagents with explicit tool grants. Subagent Hub lets you follow progress and
  steer or stop their work.
- [pi-btw](https://github.com/dbachelder/pi-btw) opens side conversations while the main agent
  continues working.
- [pi-web-access](https://github.com/nicobailon/pi-web-access) adds web search, page fetching,
  PDF text extraction, and video understanding.
- [@juicesharp/rpiv-todo](https://github.com/juicesharp/rpiv-mono/tree/main/packages/rpiv-todo)
  keeps a visible task list above the editor so you can follow the agent's progress.
- [@juicesharp/rpiv-ask-user-question](https://github.com/juicesharp/rpiv-mono/tree/main/packages/rpiv-ask-user-question)
  adds structured clarification dialogs with selectable options, custom answers, and previews.

Side conversations and subagents are not automatically isolated workspaces. Avoid concurrent
edits to the same files; separate conversations alone do not prevent editing conflicts.

## Optional design skills

- [Impeccable](https://github.com/pbakaus/impeccable) offers design direction, critique, and visual refinement.
- [Emil Kowalski's design skills](https://github.com/emilkowalski/skills) cover design engineering and interactions.
- [Stageshow](https://benji.org/stageshow) helps with layouts while prototyping, including product UI mockups, hero demos, and bento grids.

These skills can support prototyping or implementation. They are optional and not installed with
WooStack. Follow the active workflow's scope and permissions when using them.
