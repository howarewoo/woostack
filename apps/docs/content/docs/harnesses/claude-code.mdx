---
title: Claude Code
description: Task-based dispatch with a documented per-invocation model and prompt-pinned worktrees.
---

Claude Code exposes a subagent spawn tool, documented as `Agent` in the
[tools reference](https://code.claude.com/docs/en/tools-reference). Delegation is optional for
bounded Execute work; when used, select a worker exposed by the session and verify its permissions.

## Model selection

| Condition | Model source | Override behavior |
| --- | --- | --- |
| Standard run | Definition frontmatter (`inherit` uses session model), `CLAUDE_CODE_SUBAGENT_MODEL`, then session model | Explicit one-run `model` request takes precedence only if exposed by active schema and permitted by host |
| `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` | Ignores definition frontmatter; uses `CLAUDE_CODE_SUBAGENT_MODEL` if set, otherwise session model | Disables per-invocation override; uses environment or session model |

In either selection mode, Woostack reports once when a requested model override cannot be applied,
identifying the applicable source. Normal inheritance needs no notice. See the
[forced-model contract](https://code.claude.com/docs/en/sub-agents#run-every-subagent-on-one-model)
for fork, inherited-skill, and built-in Explore cap exceptions.

## Effort and workspaces

Reasoning effort is a worker-definition and session setting. An explicit one-run effort request
requires a supported native field and host authorization; otherwise report the unsupported optional
request or block a required exact effort comparison without matching evidence.

The tool has no per-call working-directory field. A worker definition can specify
`isolation: worktree`; otherwise pass the selected workspace in the task and have the worker
verify its checkout before editing. Provider recovery belongs to Claude Code.

## Native invocation

Invoke a Woostack skill in Claude Code with its documented command, for example `/woostack-execute`
([skills](https://code.claude.com/docs/en/skills)). It is the same skill and permissions as the
`/woostack-*` form used elsewhere.

The optional [Claude Code host notes](https://github.com/howarewoo/woostack/blob/main/shared/references/hosts/claude-code.md)
record these mechanics against their sources.
