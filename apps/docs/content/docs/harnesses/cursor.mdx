---
title: Cursor / Composer
description: Custom subagent models and shared or isolated workspaces.
---

Cursor can run independent subagents concurrently. A custom subagent's definition selects its
model and options; the active tool schema governs per-call arguments. Subagents share the parent's
checkout by default. For concurrent writers, request separate workspaces and verify their
ownership before editing.

Invoke a woostack skill in Cursor by typing `/` in Agent chat and searching for the skill name
([Agent Skills](https://cursor.com/docs/skills)). It is the same skill and the same permissions as
the `/woostack-*` form used elsewhere in this documentation.

The optional [Cursor host notes](https://github.com/howarewoo/woostack/blob/main/skills/using-woostack/references/hosts/cursor.md)
record these mechanics against their sources.
