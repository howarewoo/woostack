description: Subagent workspace choices and permission inheritance.
---

Antigravity CLI (`agy`) runs subagents in separate conversation contexts. Its documented workspace
modes include inheriting the parent workspace, sharing directory storage, or creating an isolated
Git worktree. Choose a safe workspace for concurrent writers. Subagents inherit the parent's
allowed command and file scopes; permission requests return to the main interface. The active tool
schema governs any per-call model or effort fields.

Use your Antigravity CLI's own documented way to invoke a skill explicitly; a `/woostack-*` example
in this documentation names the logical command, and no Antigravity-specific invocation form is
recorded in the
[host reference](https://github.com/howarewoo/woostack/blob/main/skills/using-woostack/references/hosts/README.md#native-skill-invocation).

The optional [Antigravity host notes](https://github.com/howarewoo/woostack/blob/main/skills/using-woostack/references/hosts/antigravity.md)
record these mechanics against their sources.
