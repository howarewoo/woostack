## Start using the skills

Follow [Install skills and make a first plan](/docs/getting-started) to install WooStack in an
existing repository, create project guidance, and get a read-only plan for your README.

If you already use the skills, choose a [task guide](/docs/guides). For background on workflows,
permissions, and delivery evidence, read [Workflow maps](/docs/concepts/workflows) and
[Building rules](/docs/concepts/building-rules).
