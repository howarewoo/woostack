## Other tasks and reference

To plan a new application before any code exists, use [Whiteboard](/docs/skills/woostack-whiteboard); to
create it, ask [Execute](/docs/skills/woostack-execute) for the bounded first slice. For a read-only
investigation, use [Debug](/docs/skills/woostack-debug) or [browser QA](/docs/skills/woostack-qa). The
[command index](/docs/skills/using-woostack#command-routing) lists every other command, and each
skill's own reference page states its boundary.
