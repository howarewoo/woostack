---
title: Agent skills
description: Use task workflows inside your coding harness to plan, build, and check products.
---

Agent skills are instructions and supporting assets that guide an AI coding assistant through a
task. A coding harness is the environment that runs that assistant and gives it tools to work
with your project. Each WooStack skill owns its workflow and permission boundaries.

You can use the skills with your existing tech stack. An agent team is not required.
You decide what changes and when to merge; plans and completion reports do not authorize more work.
