title: Overview
description: "woostack's gated workflows, optional artifacts, authority boundaries, and context-management practices."
---

woostack coordinates multiperson development through explicit workflow contracts, isolated
implementation, and independent review. Git and GitHub own code and pull-request truth. Linear
projects/issues are optional artifacts for specifications, plans, and fixes.

Bounded one-PR fixes or changes use one approved task contract. Multi-increment work uses an
approved specification and ordered set of independently shippable increments. Either shape may
remain artifact-free or synchronize exact caller-supplied Linear resources.

Local memory and wisdom remain reusable engineering knowledge, not project state. Local diagnostic
reports remain non-authoritative evidence.
