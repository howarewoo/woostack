---
title: Overview
description: "woostack's local run authority, optional Linear and Plane mirror records, delivery boundaries, and context management."
---

woostack coordinates multiperson development through explicit workflow contracts, isolated
implementation, and independent review. Local run manifests under `.woostack/tmp/runs/<run-id>/`
own current product scope, increment contracts, and execution state for builds and post-diagnosis
fixes, with optional Linear or Plane mirroring (`artifacts.provider: "linear"` or `artifacts.provider: "plane"`). Git and GitHub own code and
pull-request truth.

Every build manages one high-level specification plus direct increment contracts with dependency
relations in its retained run manifest. After root-cause proof, every Fix uses the same local run
structure for its complete specification plus a strict direct-issue chain. Bounded changes remain
artifact-free; other artifact use remains opt-in.
[woostack-reflect](/docs/skills/woostack-reflect) suggests novel durable rules from a fixed
active-conversation snapshot and routes each finding to the narrowest applicable rule or canonical
skill owner. Local diagnostic reports remain non-authoritative evidence.
