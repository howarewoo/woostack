---

woostack coordinates multiperson development through explicit workflow contracts, isolated
implementation, and independent review. Git and GitHub own code and pull-request truth. Selected
build/standalone-plan persistence uses one project, one parent plan issue, and one native child issue
per increment; a proved fix prompt binds or creates one issue after root-cause proof and never creates
a project hierarchy. Policy alone makes no provider call.

Bounded fixes use one approved task contract and one issue record after proof. Multi-increment work
uses an approved specification and ordered independently shippable increments. Bounded changes remain
Linear-free.

Session learning suggests novel durable rules for the narrowest applicable `AGENTS.md`. Local
diagnostic reports remain non-authoritative evidence.
