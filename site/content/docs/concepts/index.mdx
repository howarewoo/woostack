woostack coordinates multiperson development through the
[official Linear MCP](https://mcp.linear.app/mcp). Linear is the only development-record authority,
while Git and GitHub remain authoritative for code and pull requests. Every repository-changing
workflow is attributable to one exact issue.

There are two record shapes. A bounded one-PR fix or change uses one standalone issue. Multi-issue
work uses one Linear project, specification-bearing project updates, and an ordered set of
independently shippable increment issues. Across both shapes, explicit gates, isolated
implementation, and independent review keep decisions visible and ownership clear.

Local memory and wisdom remain reusable engineering knowledge, not project state. Local diagnostic
reports remain non-authoritative evidence. The pages below explain each boundary without
duplicating the canonical skill contracts.
