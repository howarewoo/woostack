## Choose the loop

- [Bootstrap](/docs/skills/woostack-bootstrap) creates a new project from scratch.
- [Build](/docs/skills/woostack-build) handles features that require multiple PRs.
- [Fix](/docs/skills/woostack-fix) handles bugs and root-cause work.
- [Change](/docs/skills/woostack-change) handles bounded non-bug work that fits one PR.

For operational details, see the canonical skill pages linked above.
