title: Tracking work
description: How woostack derives a current board from repository evidence and optional artifacts.
---

[woostack-status](/docs/skills/woostack-status) computes a fresh view from Git, Graphite, and
canonical GitHub data. It maintains no separate board or development ledger. Linear projects/issues
are optional specification, plan, and fix artifacts.

## What status tracks

The repository graph defines two display shapes:

- **Stacks/features:** Graphite-connected branches and PRs above the resolved integration base,
  grouped by declared plan/dependency context when available.
- **Standalone work:** a non-stacked branch/PR or bounded task with direct repository evidence.

A row exists because repository work exists, not because an artifact exists. Canonical repository,
ref, commit SHA, PR number, head/base, and ancestry establish identity; titles and branch names are
display text.

## How the board is derived

Each status run:

1. resolves the canonical repository, integration base, local branches/worktrees, and Graphite
   ancestry;
2. fully reads candidate PRs, checks, reviews, unresolved threads, merge evidence, and timestamps;
3. derives work/review/merge state from that complete snapshot;
4. optionally reads exact caller-supplied Linear artifacts and joins only through independently
   verified repository/PR identity; and
5. prints the current board, terminal counts, blockers, staleness, and one next action per row.

The
[canonical status conventions](https://github.com/howarewoo/woostack/blob/main/skills/woostack-status/references/conventions.md)
own the precise state derivation and output contract.

## Authority and failure boundaries

- The active user-approved workflow defines scope and acceptance.
- Git and GitHub own source-control, PR, review, and merge truth.
- Linear may explain an explicitly linked spec, plan, or fix but cannot create a row, grant
  permission, or override repository evidence.
- Local memory, wisdom, and diagnostic reports are supporting evidence only.

Missing Graphite may degrade to Git ancestry plus GitHub with disclosure. Missing GitHub evidence
makes affected rows `unknown` or `blocked`. Missing Linear access affects only explicitly requested
artifact enrichment. Status never synchronizes or mutates artifacts.

<Callout type="info">
  The board is a fresh repository view, not a third record system. Re-run it whenever source-control
  or review state changes.
</Callout>
