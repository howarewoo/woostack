---
title: Claude Code
description: Task-based dispatch with a documented per-invocation model and prompt-pinned worktrees.
---

Claude Code exposes a subagent spawn tool, documented as `Agent` in the
[tools reference](https://code.claude.com/docs/en/tools-reference). Delegation is optional for
bounded Execute work; when used, select a worker the session exposes and check its permissions.

Without an explicit native override, Claude Code selects the worker model from its definition's
`model` frontmatter (`inherit` selects the session model), `CLAUDE_CODE_SUBAGENT_MODEL`, then the
session model ([choose a model](https://code.claude.com/docs/en/sub-agents#choose-a-model)).
An explicit one-run `model` request can take precedence only if the active schema exposes it
and the host permits it. Normal inheritance needs no notice.

With `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1`, Claude Code instead ignores the worker definition's
`model` and prevents per-invocation selection. Woostack omits the model override; the worker uses
`CLAUDE_CODE_SUBAGENT_MODEL` when set to a model, otherwise the main conversation's model.
See the [forced-model contract](https://code.claude.com/docs/en/sub-agents#run-every-subagent-on-one-model)
for its fork, inherited-skill, and built-in Explore cap exceptions. In either case, woostack reports
once when a requested model override cannot be applied, identifying the applicable source.

Reasoning effort is a worker-definition and session setting. An explicit one-run effort request
needs a supported native field and host authorization; otherwise report the unsupported optional
request or block a required exact effort comparison without matching evidence.

The tool has no per-call working-directory field. A worker definition can request
`isolation: worktree`; otherwise pass the selected workspace in the task and have the worker
verify its checkout before editing. Provider recovery belongs to Claude Code.

Invoke a woostack skill in Claude Code with its documented command, for example
`/woostack-execute` ([skills](https://code.claude.com/docs/en/skills)). It is the same skill and the
same permissions as the `/woostack-*` form used elsewhere in this documentation.

The optional [Claude Code host notes](https://github.com/howarewoo/woostack/blob/main/skills/using-woostack/references/hosts/claude-code.md)
record these mechanics against their sources.
