Development artifacts are specifications, plans, and records retained for history or explicit
provider-aware workflows. Prepare and Plan exchange complete plain packets and use GitHub's native
parent/child graph as the active planning handoff; they do not allocate a local run or mirror record.
Existing `.woostack/tmp/runs/<run-id>/` files remain readable user data and are never migrated or
mutated. Execute accepts one complete bounded task and does not consume a Project or run as executable
scope.

| `artifacts.provider` | Storage/configuration | Effect |
| --- | --- | --- |
| omitted or `"local"` | [Local](/docs/configuration/artifacts/local) | No provider calls for Prepare, Plan, Ideate, Harden, or goal-only Execute; retained historical files are not rewritten. |
| `"github"` | [GitHub](/docs/configuration/artifacts/github) | Explicit provider-aware workflows use host-authenticated `gh`; Plan's direct issue publication remains its own contract. |
| `"linear"` | [Linear](/docs/configuration/artifacts/linear) | Explicit surviving provider-aware workflows use the authenticated official Linear MCP; Prepare and Plan do not mirror. |
| `"plane"` | [Plane](/docs/configuration/artifacts/plane) | Explicit surviving provider-aware workflows use the authenticated official Plane MCP; Prepare and Plan do not mirror. |

## Guarantees

Configuration is non-secret policy. It never grants permission to access a provider, approve artifact
content, or perform repository work. Credentials remain in the host's MCP, OAuth, or `gh` secret store.

Before each supported provider operation, woostack checks that the official interface supports it.
Paginated reads must include every page. Before creating a resource, woostack allocates a stable
identity so it can recover an uncertain result without creating a duplicate. It reads each created or
recovered resource independently before making further changes. Missing, partial, ambiguous,
duplicate, or out-of-scope results stop that provider operation.

A failed mirror operation is recorded in the local manifest but does not block work based on a
complete local run. Provider synchronization never grants permission to merge a PR; agents never
merge. Goal-only Execute makes no artifact-provider calls unless an exact issue association or requested
provider operation is selected. Execute with an
explicit exact GitHub issue input performs the required read of that issue through an authorized
GitHub capability (native tools preferred; host-authenticated `gh` supported); it does not select an
artifact provider or require provider configuration, a Project, a mirror, or a persisted plan.

The canonical implementation rules live in the
[local run artifact and provider mirror contract](https://github.com/howarewoo/woostack/blob/main/skills/woostack-init/references/artifact-backends.md).
