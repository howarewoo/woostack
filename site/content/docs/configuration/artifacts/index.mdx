Development artifacts are specifications, plans, and records used to resume planning work. For Build and
project-backed Fix, `artifacts` selects local storage or local storage with a remote copy.
The local run remains the source of truth. Execute accepts one complete bounded task and does not
consume a Project or run as executable scope.

| `artifacts.provider` | Storage | Effect |
| --- | --- | --- |
| omitted or `"local"` | [Local](/docs/configuration/artifacts/local) | Stores Build and project-backed Fix artifacts under `.woostack/tmp/runs/`. Makes no artifact-provider calls. |
| `"github"` | [GitHub](/docs/configuration/artifacts/github) | Keeps the local run authoritative and mirrors through the host-authenticated official GitHub CLI (`gh`). |
| `"linear"` | [Linear](/docs/configuration/artifacts/linear) | Keeps the local run authoritative and mirrors through the authenticated official Linear MCP. |
| `"plane"` | [Plane](/docs/configuration/artifacts/plane) | Keeps the local run authoritative and mirrors through the authenticated official Plane MCP. |

## Mirror guarantees

Configuration is non-secret policy. It never grants permission to access a provider, approve artifact
content, or perform repository work. Credentials remain in the host's MCP, OAuth, or `gh` secret store.

Before each provider operation, woostack checks that the official interface supports it.
Paginated reads must include every page. Before creating a resource, woostack allocates a stable
identity so it can recover an uncertain result without creating a duplicate. It reads each created
or recovered resource independently before making further changes. Missing, partial, ambiguous,
duplicate, or out-of-scope results stop that provider operation.

A failed mirror operation is recorded in the local manifest but does not block work based on a
complete local run. Provider synchronization never grants permission to merge a PR; agents never
merge. Goal-only [Execute](/docs/skills/woostack-execute) and bounded Fix make no artifact-provider
calls unless an exact issue association or requested provider operation is selected. Execute with an
explicit exact GitHub issue input performs the required read of that issue through host-authenticated
`gh`; it does not select an artifact provider or require provider configuration, a Project, a mirror,
or a persisted plan.

The canonical implementation rules live in the
[local run artifact and provider mirror contract](https://github.com/howarewoo/woostack/blob/main/skills/woostack-init/references/artifact-backends.md).
