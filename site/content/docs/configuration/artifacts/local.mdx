title: Local
description: Reference for the default local artifact store, run layout, authority, retention, and recovery behavior.
---

Local artifacts are the default. Select them explicitly with:

```json
{
  "artifacts": {
    "provider": "local"
  }
}
```

Omitting `artifacts.provider` has the same effect.

## Storage layout

Build and project-backed Fix create one run directory. After planning finishes, it contains:

```text
.woostack/tmp/runs/<run-id>/
├── .lock
├── manifest.json
├── project-spec.md
└── execution-plan.md
```

New run IDs start with their UTC creation timestamp, followed by a short goal slug:
`20260908T143052Z-timestamp-first-run-ids`. Sorting directories by name orders these runs
chronologically to the second. Existing runs retain their exact IDs and resume commands.
The [run-store contract](https://github.com/howarewoo/woostack/blob/main/skills/woostack-init/references/artifact-backends.md#owner-only-local-run-store)
defines naming and collision handling.

| Entry | Purpose |
| --- | --- |
| `.lock` | Prevents concurrent run-store operations from overwriting each other. |
| `manifest.json` | Resume state, stable task mappings, mirror results, and revision numbers that increase on each update. |
| `project-spec.md` | The complete approved specification. For Fix, this includes the proved root cause. |
| `execution-plan.md` | Ordered increments, each sized for one PR, and their dependencies. |

The run directory uses owner-only `0700` permissions. Run files use owner-only `0600` permissions.
Before replacing the manifest, the run store checks that its revision still matches the expected
value. This compare-and-swap check prevents overwriting a newer update. Replacement is atomic,
so readers do not see a partly written manifest.

The final specification and plan are each written once. Revisions require a new run; the old run
is retained.

## Authority

The local run is the source of truth for Build and project-backed Fix development artifacts. Git
and GitHub own source, branches, commits, pull requests, reviews, and merge state.
Artifacts record work; they do not authorize it.

Remote mirroring does not transfer authority away from the local run. A mirror failure is recorded in
`manifest.json` and does not invalidate complete local artifacts.

## Provider behavior

With `artifacts.provider` omitted or set to `"local"`:

- Build and project-backed Fix make no artifact-provider reads or writes.
- Standalone Plan without requested persistence makes no provider call.
- Goal-only [Change](/docs/skills/woostack-change) makes no artifact-provider reads or writes.
- Issue-backed Change performs the required read of the explicitly selected exact canonical GitHub issue
  through an authorized GitHub capability (native tools preferred; host-authenticated `gh` supported);
  it does not require provider configuration, a Project, a mirror, or a persisted plan.
- `--project` fails before provider access because it requires a configured non-local provider.
  Plan's `--parent-issue` also fails: it requires `artifacts.provider: "github"`, though no Project.

Automatic read-only Linear discovery during `woostack-init` (or GitHub discovery when
`artifacts.provider: "github"`) is a setup operation. An issue-backed Change read is driven by
explicit command input, not provider discovery. These reads do not select remote storage or
authorize later provider access.

## Retention and recovery

Completed and explicitly abandoned runs are retained. Explicit abandonment records
`status: "abandoned"` in the manifest and does not mutate a mirrored provider project.

The retired `/woostack-execute --run <exact-run-id> [--recheck]` resume command is rejected. To
continue, select one complete bounded task from the retained artifacts and supply it as
`/woostack-execute <bounded input>` (see
[Execute retired inputs](/docs/skills/woostack-execute#retired-inputs)). Titles, recent history,
branch names, and search ranking are not run selectors. Legacy tracked records remain unchanged unless
the user explicitly invokes the guarded
[woostack-init migration route](/docs/skills/woostack-init#optional-guarded-legacy-migration).
