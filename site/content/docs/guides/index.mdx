## Other tasks and reference

For a new application, use [Bootstrap](/docs/skills/woostack-bootstrap). For a read-only investigation, use [Debug](/docs/skills/woostack-debug) or [browser QA](/docs/skills/woostack-qa). [Harden](/docs/skills/woostack-harden) checks a plan against source; [Address Comments](/docs/skills/woostack-address-comments) handles unresolved review threads on an existing PR. The [skill reference](/docs/skills/using-woostack) lists current commands and their boundaries.
